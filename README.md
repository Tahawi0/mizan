# ميزان — زِن كلامك

مرجع مصري مفتوح عن التفكير الصح: المغالطات والانحيازات والأسئلة الكبيرة، بالعامية المصرية.

- المحتوى في `content/` (ملفات JSON).
- `python build.py` يبني الموقع في `docs/`، وGitHub Pages بيعرضه من هناك.
